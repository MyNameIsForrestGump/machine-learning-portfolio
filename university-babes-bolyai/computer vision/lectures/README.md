# Automated Driving — AI & Computer Vision

**Babeș-Bolyai University (UBB) | 2025**

**Course:** AI-based Computer Vision for Automated Driving  
**Industry collaboration:** Bosch

## Course Overview

This course provides an introduction to the technologies behind automated driving systems, combining computer vision, deep learning, sensor technologies, and sensor data fusion.

The lectures cover both the mathematical foundations and the engineering concepts used in autonomous vehicle perception, including camera geometry, neural networks, object detection, semantic segmentation, depth estimation, radar, and Kalman filtering.

## Lecture Overview

| Lecture | Topic | Main Concepts |
|---|---|---|
| 01 | Introduction to Automated Driving | AI-based perception, automated driving systems, vehicle sensors, and the role of artificial intelligence |
| 02 | Video Sensors I | Image representation, camera calibration, lens distortion, projective geometry, and 3D reconstruction |
| 03 | Video Sensors II | Coordinate transformations, epipolar geometry, essential and fundamental matrices, fundamental matrix estimation |
| 04 | 3D Computer Vision | Stereo vision, disparity estimation, stereo matching, optical flow, and the Lucas–Kanade algorithm |
| 05 | The Path to Foundation Models | Probability fundamentals, artificial intelligence, machine learning, deep learning, and foundation models |
| 06 | Convolutional Neural Networks | Calculus, numerical optimization, multilayer perceptrons, convolutional layers, AlexNet, and batch normalization |
| 07 | Image Classification and Object Detection | Image classification, semi-supervised learning, object detection, and an introduction to self-supervised learning |
| 08 | Image Segmentation and Depth Prediction | Image segmentation, monocular depth estimation, and bird's-eye-view representations |
| 09 | Radar-Based Driver Assistance Systems | Radar principles, driver assistance systems, adaptive cruise control, and automatic emergency braking |
| 10 | Ultrasonic Sensors | Echolocation, ultrasonic sensor architecture, signal processing, matched filtering, and echo detection |
| 11 | Sensor Data Fusion | Sensor uncertainty, state observers, Kalman filters, and extended Kalman filters |
| 12 | Connectivity | Connected vehicles, vehicle-to-vehicle communication, connectivity technologies, and data analysis |

## Main Areas of Study

### 1. Computer Vision and 3D Geometry

- Camera models and calibration
- Projective and epipolar geometry
- Essential and fundamental matrices
- Stereo vision and disparity estimation
- Optical flow and 3D reconstruction

### 2. Machine Learning and Deep Learning

- Mathematical foundations of machine learning
- Convolutional neural networks
- Numerical optimization for deep learning
- Image classification and object detection
- Semantic segmentation and depth estimation
- Foundation models

### 3. Automotive Sensor Technologies

- Camera-based perception
- Radar sensors
- Ultrasonic sensors
- Sensor uncertainty and measurement processing

### 4. Sensor Fusion and Autonomous Systems

- State estimation
- Kalman filtering
- Extended Kalman filtering
- Multi-sensor data fusion
- Connected and automated vehicles
