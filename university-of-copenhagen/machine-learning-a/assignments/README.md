# Machine Learning A — Home Assignments

**University of Copenhagen | MSc Computer Science | 2026**

This directory contains my coursework, Python implementations, experimental results, and technical reports developed as part of the Machine Learning A course at the University of Copenhagen.

The assignments combine mathematical foundations, statistical learning theory, and practical machine learning techniques.

## Assignment Overview

| Assignment | Main Topics |
|---|---|
| **HA1** | Supervised learning, nearest-neighbor methods, generalization, and evaluation of learning algorithms |
| **HA2** | Data preprocessing, feature scaling, and the importance of data representation |
| **HA3** | Optimal classification, probabilistic decision rules, and classification loss |
| **HA4** | Additional coursework — documentation to be added |
| **HA5** | Statistical dependence, confidence intervals, generalization bounds, convolutional neural networks, Sobel filters, and data augmentation |
| **HA6** | Function approximation, basis representations, and machine learning experiments |

## Repository Organization

Each assignment may include:

- **Python source code:** Implementations of algorithms and experiments.
- **Jupyter notebooks:** Interactive experiments, visualizations, and analysis.
- **Technical reports:** Mathematical derivations, methodology, results, and conclusions.
- **README files:** Assignment-specific documentation and instructions for reproducing experiments.
