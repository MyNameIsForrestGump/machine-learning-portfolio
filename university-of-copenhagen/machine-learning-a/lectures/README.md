# Machine Learning A — Lecture Notes

**University of Copenhagen | MSc Computer Science | 2026**

This directory contains lecture materials from the Machine Learning A course at the University of Copenhagen.

The course covers fundamental machine learning algorithms, statistical learning theory, neural networks, and unsupervised learning methods.

## Lecture Overview

| Lecture | Topic | Main Concepts |
|---|---|---|
| 1 | Course Introduction | Introduction to machine learning, artificial intelligence, and real-world applications |
| 2 | The Learning Problem | Supervised learning, nearest neighbors, generalization, regularization, cross-validation |
| 3 | Linear Regression | Least squares, gradients, nonlinear feature transformations, overfitting, regularization |
| 4 | Concentration of Measure | Markov's inequality, Chebyshev's inequality, Hoeffding's inequality, confidence intervals |
| 5 | Linear Classification | Linear classifiers, logistic regression, perceptron learning, classification margins |
| 6 | Trees and Forests | Decision trees, CART, ensemble methods, random forests |
| 7 | Neural Networks | Neural network architectures, loss functions, backpropagation, gradient-based learning, regularization |
| 8 | Generalization Bounds | Finite and countably infinite hypothesis classes, estimation and approximation tradeoffs |
| 9 | Deep Learning | Convolutional neural networks, dropout, residual learning, data augmentation, batch and layer normalization |
| 10 | Principal Component Analysis | Matrix decomposition, PCA, dimensionality reduction, preprocessing |
| 11 | Clustering | K-means, K-means++, cluster selection, K-medoids, K-medians |
| 12 | Stochastic Neighbor Embedding | Nonlinear dimensionality reduction, SNE, t-SNE, visualization of high-dimensional data |
